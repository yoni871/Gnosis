# About-page content and navigation

The editorial About page reuses LandingHeader, LandingFooter, the existing
self-hosted Cormorant Garamond/Inter fonts and public-page palette. No photograph,
new image asset, dependency, reader implementation or authentication change is
required. The desktop contents list sticks within normal document scrolling;
mobile uses a compact disclosure. Anchors preserve hashes and keyboard focus,
respect reduced motion and follow scrolling. Optional one-shot text/card motion
has visible defaults and is canceled on reduced-motion changes and unmount.

The previous About page did not contain the four passage quotations/explanations
referenced in the brief. The owner explicitly approved verified KJV quotations
and concise new explanations instead. Quotations are complete verse text,
including their original ending punctuation; only visual markup underlines the
word “knowledge.” Greek forms/transliterations follow the supplied brief.
Contextual explanations are original editorial summaries, not historical
commentary quotations or claims that the word has a single meaning everywhere.

Public-domain KJV verification sources:

- [Luke 1:77](https://www.biblegateway.com/passage/?search=Luke+1%3A77&version=KJV)
- [Romans 11:33](https://www.biblegateway.com/passage/?search=Romans+11%3A33&version=KJV)
- [Philippians 3:8](https://www.biblegateway.com/passage/?search=Philippians+3%3A8&version=KJV)
- [2 Peter 3:18](https://www.biblegateway.com/passage/?search=2+Peter+3%3A18&version=KJV)

Each card is a single semantic link to the existing chapter route, with `verse`
and `translation=KJV` query parameters. The reader already selects the destination
verse and scrolls it into view. No reader files or PR #29 files are changed.
The original Gnosticism distinction is preserved; current study tools are
separated from future research-platform plans.
