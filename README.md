# Gnosis

Run the complete local development environment with Node 22 and Docker Desktop:

```sh
npm run local:update
```

Open http://localhost:5173. Local verification emails: http://127.0.0.1:8025.
After pulling main, rerun the same command; your local users and saved reader data
are preserved. See [Local development](docs/Local_Development.md) for setup,
licensing, optional provider credentials, security and troubleshooting.
